# Data Directory

This directory holds EEG recordings and extracted features.

## Structure

```
data/
  raw/          - Patient directories containing .edf files and summary annotations
  processed/    - Feature matrices (.mat) generated by prepare_dataset.m
```

## Obtaining Data

The demo script (`run_demo`) automatically downloads a single CHB-MIT recording (`chb01_03.edf`) for local verification.

For the full dataset, download patient folders from PhysioNet and place them in `data/raw/`:

https://physionet.org/content/chbmit/1.0.0/

The `.edf` files and generated `.mat` files are excluded from version control via `.gitignore`.
